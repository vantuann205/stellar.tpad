# Stellar TPad User Guide

## Before you start

1. Install the Freighter wallet extension.
2. Select **Mainnet** in Freighter.
3. Keep enough XLM for the account reserve and transaction fees.
4. Open [Stellar TPad](https://stellartpad-production.up.railway.app/).

## Connect a wallet

Select **Connect Wallet**, approve the Freighter request and confirm that the
shortened address shown by the application matches the active wallet.

## Create a token

1. Select **Create Coin**.
2. Enter the token name, symbol, description and optional social links.
3. Review the 1 XLM launch fee.
4. Approve the payment and token-creation transactions in Freighter.
5. Wait for the Mainnet confirmation before leaving the page.

## Buy or sell

1. Open a token page.
2. Choose **Buy** or **Sell** and enter an amount.
3. Review the quote and slippage protection.
4. Approve the transaction in Freighter.
5. Confirm the resulting transaction in the activity panel or Stellar Explorer.

## Safety

- Never share a mnemonic phrase or secret key.
- Verify the domain and Mainnet network before signing.
- Read every Freighter confirmation; rejected transactions do not execute.
- Keep at least the Stellar minimum account reserve in the wallet.
